# Documentos de planificación

Estos documentos se escribieron **antes y durante** la construcción del sitio, como research, estrategia y especificación. El código es la fuente de verdad hoy — varias decisiones documentadas acá cambiaron en el camino (por ejemplo: Firebase Storage se reemplazó por imágenes en Firestore, el modelo de "encuentro" se sacó y todo vive a nivel instancia, las instancias son siempre privadas). Se conservan como contexto histórico, no como spec vigente.
